# Blossom Delight - Online Flower Shop Website

A simple, responsive, and user-friendly online flower shop web application developed for **SLIATE (Sri Lanka Institute of Advanced Technological Education)** as part of the Higher National Diploma in Information Technology (HNDIT) 1st Semester Individual Project.


This web application allows customers to browse floral products by occasion, view details and pricing, manage a shopping cart, place online orders, and contact the shop. It also includes an administrative panel to add new floral products dynamically.

---

## 📸 Features

### 🛒 Customer Features
- **Home Page / Hero Section:** Engaging landing banner with call-to-action navigation.
- **Product Gallery:** Grid display of flowers with image, description, and real-time prices.
- **Category Filtering:** Filter products by occasion (Birthday, Wedding, Anniversary, Gift Arrangements).
- **Shopping Cart:** Add products, view total cost dynamically, and simulate online order placement.
- **About & Contact Forms:** Dedicated sections providing shop background and customer inquiry forms.

### ⚙️ Administrative Features
- **Add Products:** Form for shop administrators to introduce new flower listings into the store's inventory dynamically.

---

## 🛠️ Tools & Technologies
- **HTML5:** Webpage structure and layout.
- **CSS3:** Styling, responsive design grid, modals, and user interface controls.
- **JavaScript (ES6):** Cart management, dynamic filtering, DOM rendering, and user interactivity.
- **Visual Studio Code:** Primary code editor.
- **Google Chrome:** Testing and debugging browser.
