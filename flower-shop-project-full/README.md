# Blossom Delight - Online Flower Shop Website (Bootstrap Version)

A responsive online flower shop web application featuring **Bootstrap 5 styling** and a **JavaScript Admin Login modal system**, developed for **SLIATE (Sri Lanka Institute of Advanced Technological Education)** as part of the Higher National Diploma in Information Technology (HNDIT) 1st Semester Individual Project.

---

## 🔑 Access Rules & Roles
- **Customers (No Login Required):** Can freely browse flowers, filter categories, view pricing, add items to cart, and place orders directly without logging in.
- **Admin (Password Protected):** Requires logging in via the Admin Login button (`Username: admin`, `Password: admin123`). Grants full access to add new products to the inventory and manage orders.

---

## 🛠️ Tools & Technologies
- **HTML5:** Semantic structural layout.
- **Bootstrap 5:** Responsive design, grid layout, UI components, modals, badges, navigation bar, and buttons.
- **Custom CSS:** Additional theme styling and overlay effects.
- **JavaScript (ES6):** Admin authentication modal system, cart state, dynamic filter rendering, and product management.
